# СБ-18-00 — Unity, перший рік

Навчальний проєкт IT-FRIENDS, 2026–2027 навчальний рік. Група розпочала роботу в Unity 19 вересня 2026 року.

На першому занятті знайомилися з редактором і оформлювали мапу готовими моделями з паку LowPolyConstructor.

## Як відкрити

1. Додайте цю папку в Unity Hub як наявний проєкт.
2. Використовуйте Unity **6000.3.15f1**.
3. Відкрийте сцену `Assets/Scenes/SampleScene.unity`.

У репозиторії зберігаються `Assets`, `Packages` та `ProjectSettings`. Unity створить локальний кеш і робочі файли після відкриття проєкту.

Це поточний збережений стан навчального проєкту; історія Git починається 20 вересня 2026 року.
